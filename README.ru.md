# Archi

[English](README.md) · **Русский**

**Личный агент на вашем сервере, с которым вы общаетесь в Telegram.** Archi живёт на вашей Linux-машине,
работает через CLI агента для кода (Claude Code или OpenAI Codex) по вашей подписке и отвечает в Telegram:
в личке с ботом или в группе, причём каждый топик ведёт отдельный разговор. У агента полный доступ к
серверу: он ставит пакеты, поднимает сервисы, пишет и чинит код, следит за собой.

> Статус: v0.1 в разработке. Этот README описывает то, что войдёт в первый релиз.

## Что внутри
- **Telegram как основной вход.** Личка с топиками или группа с топиками: у каждого топика своя память
  и своя сессия, топики работают параллельно. Archi сразу видит, что топик создан, переименован, закрыт
  или удалён, и умеет создавать топики сам. Вторым входом можно подключить Element (Matrix): там
  разговором становится каждая комната.
- **Ваша подписка, без счетов за API.** Claude Code (подписка Claude) или Codex (подписка ChatGPT);
  переключается командой `/provider` для каждого разговора отдельно.
- **Ход работы на виду.** Пока задача идёт, видно её шаги. Долгую работу агент выносит в фоновую задачу,
  которая переживает его ответ, а когда она закончится, агент сам напишет в тот же разговор.
- **Самообслуживание.** Сервисы systemd, безопасный перезапуск (дожидается конца текущих задач),
  проверка собственного кода перед перезапуском, обновление одной командой `archi update`.
- **Память и самообучение.** Заметки, журнал сессий и поиск по памяти. Время от времени агент в фоне
  разбирает прошедший разговор: записывает факты и уроки, правит свои навыки и коротко сообщает, что
  поменял.
- **Навыки из коробки:** брейншторм, придирчивое ревью собственных изменений, индекс репозитория,
  ответ в виде HTML-страницы, веб-страница в Markdown, проверка текста перед публикацией (`clean-copy`),
  набор навыков по дизайну интерфейсов и необязательные навыки, которым нужны отдельные инструменты:
  наборы картинок (ключ Gemini API), моделирование в Blender (Blender MCP), монтаж видео (ffmpeg).

## Быстрый старт
На чистом сервере с Ubuntu 22.04+ или Debian 12+, от root:
```bash
curl -fsSL https://raw.githubusercontent.com/Evenorchik/archi/main/install.sh | bash
```
Установщик:
1. ставит git, Python и ffmpeg и кладёт Archi в `/opt/archi` (это git-репозиторий);
2. спрашивает токен Telegram-бота (бота создают через @BotFather) и проверяет его;
3. спрашивает, какая у вас подписка, Claude (Claude Code) или ChatGPT (Codex), ставит нужный CLI
   официальным установщиком и логинит без браузера на сервере: вы открываете ссылку на телефоне или
   ноутбуке и вставляете обратно код;
4. по желанию принимает ключ OpenAI API для голосовых;
5. запускает сервис `archi-telegram` и показывает одноразовый код: откройте бота, нажмите Start и
   отправьте код.

После этого агент пишет первым: представляется, называет сервер, IP и подписку и спрашивает, как его
назвать и как вы хотите с ним работать. Имя он сам пропишет везде, включая имя бота.
Повторный запуск установщика ничего не ломает: код и настройки остаются, пока вы сами не выберете
перенастройку.

### Команды на каждый день
- `archi status`: сервисы, подписка, модель, привязка владельца, текущие задачи (секреты не выводит)
- `archi logs -n 100`: последние строки логов
- `archi restart --when-idle`: перезапуск, когда текущие задачи закончатся (так перезапускается и сам агент)
- `archi update`: обновление с GitHub с сохранением ваших локальных правок; конфликт откатывается и
  показывается, ничего не перезаписывается силой
- `archi validate`: проверка кода и конфига перед перезапуском
- `archi setup voice` (ключ OpenAI), `archi setup provider codex` (поставить и залогинить второй CLI),
  `archi setup telegram` (новый токен бота), `archi setup matrix` (подключить Element)
- `archi pair --reset`: привязать другой аккаунт Telegram
- `archi identity set-name "Имя"`: переименовать агента (он делает это сам, когда вы дадите ему имя)
- `archi job list`: фоновые задачи; `archi learn status`: настройки самообучения

### Element (Matrix)
`archi setup matrix` спросит адрес сервера, логин и пароль отдельного аккаунта для бота и ваш Matrix ID.
Пароль не сохраняется, сохраняется только токен доступа. Дальше пригласите бота в комнату из Element.
Комната должна быть **без шифрования**: читать зашифрованные комнаты бот не умеет, поэтому из такой
комнаты он выйдет и напишет, как создать обычную. Каждая комната становится отдельным разговором, бот
отвечает только вам. Команды в Element начинаются с `!` (`!new`, `!status`, `!help`): символ `/` Element
оставляет за своими командами.

### Установка без вопросов
На каждый вопрос установщика есть переменная окружения, список в начале `install.sh`. Например:
```bash
curl -fsSL https://raw.githubusercontent.com/Evenorchik/archi/main/install.sh | \
  ARCHI_NONINTERACTIVE=1 ARCHI_BOT_TOKEN=<токен бота> ARCHI_PROVIDER=claude \
  ARCHI_CLAUDE_OAUTH_TOKEN=<токен из claude setup-token> bash
```

## Безопасность
По умолчанию Archi работает от root и выполняет всё, что решит его агент. Ставьте его на отдельный
сервер, не открывайте бота посторонним (он отвечает только привязанному владельцу) и делайте бэкапы.
